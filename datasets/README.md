## 数据集说明

- **12 首日语主组**：由 `s01`–`s10`、`s12`、`s15` 组成，合计 522 行正文、5,370 个日语读音单元，用于所有核心对齐、分离与注音实验。
- **跨语种与方言样本**：`s11` 为前 10 行日语、后 13 行粤语的现场演唱会录音；`s13` 与 `s14` 共用同一段潮汕话歌曲录音，分别提供假名近似注音和潮汕方言俗字标注，用于检验日语声学模型与多语言模型在非目标语种上的边界表现。
- **背景歌词与叠唱**：`s03`、`s06`、`s07`、`s15` 包含带时间戳的背景合唱行（`ttm:role="x-bg"`）。背景歌词不作为对齐目标，但其对应的时间区间用于评估主唱歌词在叠唱干扰下的对齐准确率。
- **输入剥离规则**：人工读音组（G1、G2）仅从 TTML 提取歌词正文与 Ruby 注音，剥离所有时间戳；自动分词注音组（G3）仅提取每行纯文本正文，剥离人工分词、注音与时间戳。详细评分规则见 [测试集与评价方法](../reports/methods.md)。

录音和歌词的权利归相应权利人；本仓库的源码许可不授予这些音乐与歌词内容的额外使用权。
